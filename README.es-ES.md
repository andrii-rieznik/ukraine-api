

# API de Ucrania

¿Conoces algún API de una institución estatal ucraniana, empresa privada u organización pública que no esté en la lista? Entonces, abre un [pull request](https://github.com/andriyreznik/ukraine-api/pulls) o crea un [issue](https://github.com/andriyreznik/ukraine-api/issues).

## Información general

### Accesibilidad

#### Público

El API se puede usar de forma gratuita, incluso si requiere autorización.

#### Privado

Debe tener una "relación" con la empresa que expone el API, ya sea de forma pagada o gratuita.
